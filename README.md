El estudio evalúa el rendimiento fuera de muestra del modelo de
aprendizaje automático Random Forest (RF) en la predicción del incumplimiento
de los External Quantitative Performance Criteria (QPCs) o metas externas de
los programas de préstamo del Fondo Monetario Internacional (FMI). 

Para el entrenamiento y testeo del modelo se ha utilizado la base de datos Monitoring
of Fund Arrangements (MONA) del FMI. 

El modelo se entrenó con información entre 2003 y 2021, y se testeó su capacidad de predicción para el período 2022-
2024. 

El modelo logra un rendimiento F1w de 0,87 para los 38 países deudores
en el set de test, de 0,88 para los cuatro principales deudores de la cuenta general
de recursos del FMI -Argentina, Ucrania, Pakistán y Egipto-, y de 0,94 para el
principal deudor del FMI -Argentina. 

En particular, el modelo RF entrenado
con información entre 2002 y 2021 emite sucesivas señales tempranas de alerta
sobre el incumplimiento de un número significativo de metas externas por parte
de Argentina en el período 2022-2024. 

La selección de variables del modelo
sugiere que cuanto mayor es el retraso cambiario previo al programa, y menor
es el ajuste del tipo de cambio al inicio del mismo, mayor es la probabilidad de
incumplimiento de las metas externas futuras del programa. Dado un escenario
de atraso cambiario previo al inicio del programa, un programa cuyo diseño
prevé una financiación generosa y un ajuste cambiario inicial poco ambicioso
tiene más probabilidades de incumplir sus metas externas futuras.
